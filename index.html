The Governance Tuple

MIT Licensed Stdlib Only Python 3.11+

An Atomic Record for Auditable Agentic AI Decision-Making

Abstract: We present the Governance Tuple, an atomic record format that provides end-to-end auditability for autonomous AI agent decision-making. The framework defines five tuple types -- CONTRACT, DCT (Delegation Capability Token), DCTX (Delegation Context), EVIDENCE, and ATTEST -- that together form a tamper-evident, hash-chained audit trail linking every agent action to its authorizing delegation, governing contract, and verification outcome. We introduce a trust-decay model that dynamically bounds delegation chain depth based on the delegatee's trust score and the operation's risk tier, and a fail-closed signature enforcement policy that ensures no governance record can be written without cryptographic attribution. The framework is evaluated through a reference implementation that is stdlib-only, MIT-licensed, and designed for peer-review verification of all implementation claims.

Trust-Decay Formula

The dynamic depth bound is computed as:

delta_effective = min(delta_max, floor(tau / tau_o))

where tau_o is the per-risk-tier threshold:

Risk Tiertau_o
LOW0.15
MEDIUM0.20
HIGH0.25
CRITICAL0.40
