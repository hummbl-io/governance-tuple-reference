# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately:

1. **Do not open a public GitHub issue.**
2. Go to [Security Advisories](https://github.com/hummbl-io/governance-tuple-reference/security/advisories/new) and create a private security advisory, or email `security@hummbl.io`.
3. Include a description of the vulnerability, steps to reproduce, and potential impact.

We aim to respond within 48 hours and coordinate a responsible disclosure timeline.

## Standard

This repository adheres to the HUMMBL Organization Security Standards.
See `hummbl-io/hummbl-governance` for organization-wide security baselines.
